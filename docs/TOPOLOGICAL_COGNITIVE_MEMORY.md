
# Topological Cognitive Memory Runtime

TopoSpace alpha5 separates agent memory into three interacting topological layers:

- Working topology: short-lived execution state and active context.
- Episodic topology: task/incident/session experience.
- Semantic topology: repeatedly useful, high-confidence knowledge.

Successful repeated use increases memory utility. Consolidation promotes memories across layers, while layered
topological recall favors durable semantic knowledge without excluding current working state. Recalled memories
can be projected directly into the self-reorganizing Task-Agent-Tool-Memory-Context execution topology.

TorusDB remains the durable storage boundary; this module defines the cognitive/topological organization above it.
