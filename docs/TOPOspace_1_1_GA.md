
# TopoSpace 1.1 GA

TopoSpace 1.1 packages the generalized topological runtime as a production release:

- generalized admissible geometry above flat Lp,
- learned geometry policy,
- unified Memory/Tool/Skill/Plan routing,
- cross-domain coupled product space,
- state-conditioned learned topological field,
- joint A_theta + C_theta optimization,
- safe online learning with shadow/champion/challenger, staged rollout and rollback,
- runtime server / SDK / tenant isolation,
- TorusDB durable-memory integration path,
- governance, trust, release manifest and SBOM assets.

API v1 remains the public compatibility boundary. Production claims about token or cost savings should be based
on representative customer workloads; included GA benchmarks are candidate-space engineering benchmarks.
