
# TopoSpace 1.0 GA

TopoSpace 1.0 freezes the v1 middleware/runtime contract and packages:
- framework-agnostic lifecycle middleware
- adaptive topology/context optimization
- TorusDB Agent Memory adapter and recall path
- multi-agent selection and token optimization
- self-optimizing Autopilot with governed PolicyOps
- enterprise trust/governance components
- Kubernetes/Helm and Docker/Compose deployment assets
- install doctor, release manifest, SBOM and frozen API contract

Validation in this package includes a real local HTTP round-trip through the configurable TorusDB HTTP adapter.
It does not claim validation against a customer's actual TorusDB, Redis, PostgreSQL, IAM, TLS ingress or LLM.
Those remain staging acceptance requirements for each deployment.
