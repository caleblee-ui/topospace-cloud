
# TopoSpace Graph Web SDK

Framework-free Web Component for TopoSpace graphs.

```html
<script src="/topospace-graph.js"></script>
<div id="topology"></div>
<script>
  const graph = TopoSpaceGraphSDK.mount("#topology", payload);
  graph.addEventListener("node-select", event => console.log(event.detail));
</script>
```

React/Vue/Svelte can wrap `<topospace-graph>` directly because it is a standards-based custom element.
The runtime JSON contract is generated by `runtime/web_graph_payload.py`.
